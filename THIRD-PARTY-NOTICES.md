# Third-party source references

This kit is an integration layer and does not redistribute the Android/GammaOS/R36S source trees.

- GammaOS Core Distribution: Apache-2.0 project repository
  https://github.com/TheGammaSqueeze/GammaOSCoreDistribution
- R36S device tree: source repository
  https://github.com/andr36oid/android_device_gameconsole_r36s
- R36S common tree: source repository
  https://github.com/andr36oid/android_device_gameconsole_common
- R36S kernel: source repository
  https://github.com/andr36oid/android_kernel_gameconsole_r36s

Check each upstream repository's license/notice files before redistributing a combined source tree or binary build.
